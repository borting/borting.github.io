紀錄一下 draw.io linux desktop 版本的安裝方式.
這樣就不用每次畫圖都要開 browser 和 google drive 了.

# Install Draw.io

Download latest deb package release from [github](https://github.com/jgraph/drawio-desktop/releases).
Then, install deb package.
```shell
sudo apt -f install ./drawio-amd64-*.deb
```
